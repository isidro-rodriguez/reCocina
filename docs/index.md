# 🍳 reCocina

Recetario casero organizado por categorías.

## Cómo usarlo

- Navega por la **barra lateral** para ver las categorías.
- Cada receta incluye **ingredientes**, **preparación paso a paso** y **foto**.
- Las fotos se muestran bajo el título de cada receta.

## Categorías

- Aperitivos
- Arroz
- Pasta
- Carne y Pollo
- Pescado y Mariscos
- Verduras, Legumbres y Potajes
- Sopas y Cremas
- Salsas
- Postres

## Consejos rápidos

- Lee toda la receta antes de empezar a cocinar.
- Usa ingredientes de calidad; en cocina casera marca la diferencia.
- Ajusta las cantidades a tu número de comensales.
